THE INPUT DATA
What are we working with?

The web contains billions of tables. Each has columns and rows of data — but they are messy, fragmented, and inconsistent. AutoMap mines these tables to find hidden mapping relationships automatically.

🔍

What is a Mapping Relationship?

A two-column table where each left value maps to exactly one right value — useful for data integration like auto-join and auto-fill.

Country → ISO Code
South Korea → KOR
Germany → DEU
France → FRA
⚡

Why is it Hard?

The same mapping exists in thousands of different tables, each using different names for the same entity. No single table is complete.

Table A: South Korea → KOR
Table B: Korea, Republic of → KOR
Table C: KOREA REPUBLIC OF → KOR
→ All the same! But written differently.
